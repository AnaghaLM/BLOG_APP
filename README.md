# MERN Notes Application

## Features
- User Registration
- User Login with JWT Authentication
- Create Notes
- Edit Notes
- Delete Notes
- Category Filtering
- Protected Routes

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS

## Backend Setup

cd server  
npm install  

Create a .env file and add:

connection_string = mongodb_connection_string  
jwt_password = jwt_secret  

Run backend:

npm start

## Frontend Setup

cd frontEnd  
npm install  
npm run dev

Frontend runs on:
http://localhost:5173
